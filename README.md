# microAI

Proyecto de grado: Diseño de un Agente de Inteligencia Artificial para la Priorización Geográfica del Despliegue Estratégico de Microcrédito Digital en Colombia.

## Estructura
- `data/`: datos crudos, externos y procesados
- `notebooks/`: desarrollo paso a paso
- `src/`: funciones auxiliares
- `reports/`: salidas y reportes
